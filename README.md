# Oref-Live-Alerts 🚨

לוח בקרה מינימליסטי ללא צורך בהתקנה להצגת התראות פיקוד העורף בזמן אמת.

**הבהרה:** זהו פרויקט צדדי ניסיוני שפותח באמצעות Gemini. המערכת לא עברה בדיקות מעמיקות ואין להסתמך עליה ככלי בלעדי להצלת חיים.

## 🚀 הוראות הפעלה מהירות

**שלב 1 - הפעלת השרת:**
הרץ את הקובץ `server.bat` (לשימוש מקומי) או `server-admin.bat` (לגישה ממכשירים אחרים ברשת).

> ⚠️ **שים לב:** חובה להשאיר את חלון השרת פתוח בזמן השימוש. ללא הרצת השרת, האפליקציה לא תוכל למשוך נתונים והיא לא תעבוד.

**שלב 2 - צפייה בממשק:**
מומלץ להשתמש בדפדפן **Google Chrome** ולפתוח דרכו את הקובץ `oref.html`.

## 🖥️ אפשרויות תצוגה ומיקוד

המערכת מאפשרת התאמה אישית של המעקב לצרכים שלך:

* **חיפוש ומיקוד ביישוב:** ניתן להזין שם של עיר או אזור ספציפי בתיבת החיפוש כדי לעקוב אחר מצב ההתראות וההיסטוריה באותו אזור בלבד.
* **תצוגת מסך מפוצל:** באמצעות כפתור "פיצול מסך", ניתן להציג שני לוחות בקרה במקביל – למשל, צד אחד למעקב ארצי וצד שני ממוקד ליישוב ספציפי.

## 🛠️ סביבת פיתוח והסבר על השרתים

האפליקציה פותחה ונבדקה בסביבת Windows באמצעות דפדפן כרום. המערכת מושכת נתוני היסטוריה ומציגה התראות חיות

קיימות שתי גרסאות של השרת:

* **שימוש מקומי (server.bat):** השרת יאזין לכתובת המקומית בלבד. מתאים כאשר הקליינט והשרת רצים על אותו המחשב.
* **שימוש רשתי (server-admin.bat):** דורש הרשאות מנהל (Admin) כדי לפתוח את הפורט ב-Firewall של Windows. גרסה זו מאפשרת למחשבים אחרים באותה הרשת להתחבר לשרת ולקבל את הנתונים.

> ⚠️ **שים לב:** חובה להשתמש באחד מהשרתים (server.bat או server-admin.bat) אחרת תתרחש חסימה (CORS) שתמנע מהאפליקציה למשוך נתונים ולעבוד כראוי.
