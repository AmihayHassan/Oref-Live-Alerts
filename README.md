# Oref-Live-Alerts 🚨

לוח בקרה מינימליסטי להצגת התראות פיקוד העורף בזמן אמת.
**הבהרה:** זהו פרויקט צדדי ניסיוני שפותח באמצעות Gemini. המערכת לא עברה בדיקות מעמיקות ואין להסתמך עליה ככלי בלעדי להצלת חיים.

## הוראות הפעלה מהירות 🚀
1. **הפעלת השרת:** הרץ את הקובץ `server.bat` (לשימוש מקומי) או `server-admin.bat` (לגישה ממכשירים אחרים ברשת).
2. **צפייה בממשק:** מומלץ להשתמש בדפדפן **Google Chrome** ולפתוח דרכו את הקובץ `oref.html`.

## סביבת פיתוח והסבר על השרתים 🛠️
האפליקציה פותחה ונבדקה בסביבת Windows באמצעות דפדפן כרום, שם נבחנה הפונקציונליות הבסיסית שלה. המערכת מושכת נתוני היסטוריה ומציגה התראות חיות.

* **server.bat:** שרת Proxy בסיסי המיועד לעבודה על המחשב שבו הוא רץ בלבד.
* **server-admin.bat:** מגדיר חוק ב-Firewall של Windows המאפשר למכשירים נוספים באותה הרשת לצפות בלוח הבקרה.
